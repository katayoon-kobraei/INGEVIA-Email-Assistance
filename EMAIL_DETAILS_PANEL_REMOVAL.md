# Email details panel removal

The right-side **Email details / Detalles del correo** panel was removed from the **Emails / Correos** page in both languages.

The email table now uses the full available page width. Selecting a row still updates the one-line summary panel above the table, and double-clicking a row still opens the corresponding folder.

Modified files:

- `desktop_app/main_window.py`
- `desktop_app/main_window_en.py`

Desktop UI version: 1.5
